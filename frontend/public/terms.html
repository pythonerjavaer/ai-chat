1. 产品定位

冰焰智研是合同、合规与金融文档的研究辅助工具，提供信息提取、来源检索、摘要、风险线索和可复核计算。它不是律师事务所、金融机构、证券顾问、会计师事务所或交易平台。

2. 法律工作台边界

法律工作台的输出不构成法律意见，不建立律师—客户关系，也不保证某条款在特定法域有效。签署合同、回应监管、启动诉讼或作出重大合规决定前，应由具备相应资质且了解完整事实的专业人士复核。

3. 金融工作台边界

金融工作台不提供个性化买入、卖出、持有、税务或投资组合指令，不接入实时行情，也不执行交易。文档中的历史数字不代表当前市场情况；用户应自行确认币种、单位、报告期间、公式与数据时效。

4. AI 与来源

模型可能遗漏信息、误解上下文或生成不准确内容。“证据透镜”只反映检索片段的相关度与覆盖情况，不是事实准确率、法律确定性或投资评级。没有显示来源时，不应假定输出有文档依据。

服务依赖网络、OpenAI API 与后端基础设施，可能发生限流、维护或中断。除适用法律另有规定，不保证服务持续无误或适合某一特定目的。
