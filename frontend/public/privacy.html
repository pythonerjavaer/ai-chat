PRIVACY POLICY

隐私政策

本政策说明冰焰如何处理账号、对话、文档、造界世界、招聘监控与汇总使用数据，以及数据何时会发送给 OpenAI API。

版本：2026-08-22.2
本政策适用于冰焰当前公开版本。我们只处理提供核心功能、保障账号安全和履行用户请求所必需的数据。

1. 我们处理的数据

  • 账号数据：用户名、加密后的密码摘要、隐私同意时间与版本；我们不存储明文密码。
  • 对话与文档：你主动提交的消息、会话标题、上传文档的文字内容及检索向量。
  • 造界：世界的名称、说明、规则、任务输入、结构化成果、模型输出、运行路径、Token 预估与实际用量、缓存关联和时间记录。
  • 招聘数据：你保存的岗位、行业、城市和雇主偏好，以及主动添加的公开招聘页 URL、监控名称、关键词、页面内容指纹、关键词命中、检查结果和时间。应用不保存所监控网页的完整正文。
  • 技术与使用数据：服务保存账号内部编号、规范化 API 路由、请求方法、状态码、耗时与时间，用于安全、故障排查和仅管理员可见的汇总使用概览；不写入消息正文、文档内容、密码、Prompt 或模型回复。当前应用不主动收集精确位置、通讯录、照片库、麦克风或广告标识符。

2. 使用目的

数据用于身份认证、隔离不同用户与工作区、保存历史与成果、建立私人文档索引、检索相关片段、生成回答、控制 Token 预算、精确复用相同成果、匹配岗位、检查用户指定的公开招聘页变化、防止滥用、排查故障，以及向管理员提供不含用户内容的注册量、活跃量、请求量、错误与 Token 汇总。

3. OpenAI API

聊天消息、相关历史消息、命中的文档片段和建立索引所需的文档片段会发送给 OpenAI API。造界的 lean 和 deep 模式会把该世界的规则与本次任务发送给 OpenAI；预检、规则整理的零 Token 模式、精确缓存复用和招聘网页指纹比较不会把相应内容发送给 OpenAI，但仍会由应用后端处理并按上述范围保存。应用不会把 OpenAI API Key 下发到客户端。依据 OpenAI 当前公开的 API 数据政策，API 数据默认不用于训练模型，部分内容可能按其政策用于有限期滥用监测；具体以 OpenAI API 数据控制说明为准。

4. 招聘网页检查

当你添加或刷新官网变化雷达时，应用服务器会访问该公开 HTTPS 页面；目标网站会像处理普通网络请求一样看到服务器 IP、请求时间和应用的抓取标识。我们不会把你的用户名、求职画像或其他私人内容发送给该网站。请只添加你有权访问且允许自动检查的公开页面。

5. 保存与删除

账号存在期间，对话、文档、索引、造界世界、运行历史、求职偏好和官网监控保存在应用后端数据库中。内容无关的 API 使用事件最多保存 30 天，超过期限后由服务清理。你可以单独删除对话、文档或官网监控；造界的运行历史当前没有单条删除入口，每个世界只保留最近 100 次运行。你也可以在“账号与数据”中永久删除账号；删号会级联删除该账号的会话、消息、文档、向量索引、造界世界、运行历史、Token 账本、求职画像与官网监控；尚在保存期内的必要安全与使用事件会去除账号关联并在期限届满后删除。

6. 数据安全

密码使用强哈希保存，业务接口使用 Bearer Token 鉴权，真实 OpenAI API Key 仅保存在服务端环境变量中。正式部署必须使用 HTTPS、限制跨域来源并保护数据库备份。当前 Render Free 演示实例使用临时文件系统，不承诺账号数据持久保存；正式服务必须迁移到外部持久数据库。

7. 你的选择

你可以拒绝创建账号、退出使用、通过现有入口删除对话/文档/官网监控，或永久删除账号。拒绝向 OpenAI 传输必要内容时，聊天、文档索引及造界的节能/深度模式无法提供；零 Token 规则整理、缓存查看和招聘网页指纹比较不调用 OpenAI。

8. 儿童

本产品面向具备独立民事行为能力的专业用户，不面向儿童，也不应由未成年人提交合同、财务或其他敏感资料。

9. 联系我们

可通过 项目支持入口 提交隐私、访问或删除请求。请勿在公开 Issue 中粘贴密码、API Key、合同原文或个人金融数据。
