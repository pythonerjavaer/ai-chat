隐私政策

本政策说明冰焰智研如何处理账号、对话和文档数据，以及数据何时会发送给 OpenAI API。

版本：2026-08-21
本政策适用于冰焰智研当前公开版本。我们只处理提供核心功能、保障账号安全和履行用户请求所必需的数据。

1. 我们处理的数据

  • 账号数据：用户名、加密后的密码摘要、隐私同意时间与版本；我们不存储明文密码。
  • 用户内容：你主动提交的消息、会话标题、上传文档的文字内容及检索向量。
  • 技术数据：服务为安全与故障排查产生的必要请求日志。当前应用不主动收集精确位置、通讯录、照片库、麦克风或广告标识符。

2. 使用目的

数据用于身份认证、隔离不同用户与工作区、保存历史记录、建立私人文档索引、检索相关片段、生成回答、执行用户请求的计算，以及防止滥用和排查故障。

3. OpenAI API

聊天消息、相关历史消息、命中的文档片段和建立索引所需的文档片段会发送给 OpenAI API。应用不会把 OpenAI API Key 下发到客户端。依据 OpenAI 当前公开的 API 数据政策，API 数据默认不用于训练模型，部分内容可能按其政策用于有限期滥用监测；具体以 OpenAI API 数据控制说明为准。

4. 保存与删除

账号存在期间，对话、文档和索引保存在应用后端数据库中。你可以单独删除对话或文档，也可以在“账号与数据”中永久删除账号。删号会级联删除该账号的会话、消息、文档与向量索引；依法必须保留的安全记录除外。

5. 数据安全

密码使用强哈希保存，业务接口使用 Bearer Token 鉴权，真实 OpenAI API Key 仅保存在服务端环境变量中。正式部署必须使用 HTTPS、限制跨域来源并保护数据库备份。

6. 你的选择

你可以拒绝创建账号，撤回使用，删除单条数据或永久删除账号。由于 AI 处理是核心功能，拒绝向 OpenAI 传输必要内容时，聊天和文档索引功能无法提供。

7. 儿童

本产品面向具备独立民事行为能力的专业用户，不面向儿童，也不应由未成年人提交合同、财务或其他敏感资料。

8. 联系我们

可通过 项目支持入口 提交隐私、访问或删除请求。请勿在公开 Issue 中粘贴密码、API Key、合同原文或个人金融数据。
