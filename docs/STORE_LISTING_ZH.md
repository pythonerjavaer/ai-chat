## 短描述

在寒冰条款地图与烈火信号面板中，把合同、合规和财务资料转化为带来源、口径和假设的研究线索。

## 完整描述

冰焰智研是一款证据驱动的专业文档研究工作台。

寒冰工作台聚焦合同与合规：从用户上传的资料中整理主要条款、参与方义务、日期期限、风险线索和证据缺口。

烈火工作台聚焦金融研究：提取用户资料中的关键数字，明确币种、期间与计算口径，并使用可复核工具计算增长率、净利率、ROA、ROE、流动比率、负债权益比和 CAGR。

主要能力：

- 上传 PDF、DOCX、TXT、Markdown、CSV 或 JSON；
- 在每个专业工作区内建立独立的私人资料索引；
- 流式生成回答并显示命中文件和 PDF 页码；
- 以证据、分析、缺口和下一步核查组织输出；
- 保存并继续历史研究会话；
- 单独删除对话和文件，或在应用内永久删除账号及业务数据。

重要边界：冰焰智研不构成法律意见，不提供个性化投资、税务或交易指令，不接入实时行情，也不执行交易。AI 可能出错，专业决定必须由用户和具备资质的专业人士结合完整事实独立复核。

## 审核备注初稿

本应用需要登录。请在审核后台单独提供专用测试账号，不要把账号密码写入公开仓库或商店描述。

审核路径：

1. 登录测试账号；
2. 选择“合同合规”或“金融研究”；
3. 可直接开始通用问答，或上传审核用的非敏感示例文件；
4. 流式回答会在回答下方显示来源与工具；

应用把用户主动提交的消息、相关历史消息和命中文档片段发送至 OpenAI API 生成回答；注册页在创建账号前进行明确披露并取得同意。OpenAI API Key 只保存在后端。
